# JobHunt Copilot

A modern web app to generate tailored resumes and cover letters from a job description and your experience document.

## Features

- Paste a job description or import from a URL.
- Upload your experience document.
- AI-assisted parsing of experience bullets by company and skill tags.
- Resume builder with template switching, editable sections, and bullet reordering.
- Download CV as a PDF named after the candidate.
- Cover letter tab with custom notes integration.
- Inline assistant chat for guidance and missing info prompts.
- Company/application key points pulled from web search signals.
- Submission history table saved in local storage.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
