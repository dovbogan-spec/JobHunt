# Config assets

This folder stores data-first assets used by the resume AI pipeline.

## Structure

- `resume-templates/`: template schema + rendering stubs used to populate resume fields.
- `prompts/`: prompt orchestration and agent definitions for multi-step AI workflows.

## Current assets

- `resume-templates/basic-modern-minimal-single-column.json`
- `resume-templates/basic-modern-minimal-single-column.html`
- `prompts/career-edge-orchestration.json`

Future template designs can be added as additional JSON/HTML pairs inside `resume-templates/`.
